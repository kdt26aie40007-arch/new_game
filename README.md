# 呪文合戦 ― 光線押し合い

スペースキー1つで遊ぶ、ブラウザ用の3D魔法決闘ゲームです。
杖から放つ光線を敵の光線とぶつけ合い、衝突点を敵の陣まで押し切れば勝ち、自分の陣まで押し込まれたら負けです。

## 遊び方

| 操作 | 効果 |
|---|---|
| スペースを連打 | 光線を相手側へ押し返す |
| スペースを長押し | 「バーリア！」でガード。押し返せないが、受ける押し込みをほぼゼロにする |
| Esc | 戦闘から退く |
| Enter（結果画面） | 同じ相手ともう一度戦う |

スマホでは、画面下に出るボタンをタップすると連打、押しっぱなしにすると長押しになります。

### 敵の大技

1. 敵は一定時間ごとに「チェストの構え」に入ります。画面に「相手がチェストを構えた！」と出て、敵と周囲が赤く光ります。
2. 数秒後に大技が始まります。大技の間は押し込みが通常の3倍以上になり、連打では必ず押し負けます。長押しで耐えてください。
3. 大技を耐えきると、約1.6秒間の「反撃」に入ります。この間は連打の押し返す力が1.8倍になります。

画面下の指示パネルが、今やるべきことを漢字と色で示します。

| 表示 | 色 | 意味 |
|---|---|---|
| 連打 | 金 | 通常の押し合い。連打する |
| 構え | 朱 | 大技の予兆。長押しの用意をする |
| 長押し | 青 | 大技の最中。押しっぱなしで耐える |
| 反撃 | 明るい金 | 大技の直後。一気に連打する |

## 相手

| 難易度 | 相手 | 特徴 |
|---|---|---|
| ノーマル | セビルロング尻 🗡️ | 大技の頻度が低い |
| ハード | 急げ堀田ー ⚡ | 大技の威力が高い |
| ボス | ボル痔モート 💀 | 大技の予兆が短く、通常の押しも強い |
| 裏ボス | ドビュー 🧦 | 大技と通常攻撃がほぼ絶え間なく続く |

## 動かし方

`jumon-gassen.html` をブラウザで開くだけで遊べます。ビルドやサーバーは不要です。
three.js（r128）と Google Fonts を CDN から読み込むため、インターネット接続が必要です。
WebGL が使えない環境では3D表示の代わりにメッセージが出ますが、指示パネルを見ながら遊ぶことはできます。

## 構成

すべて `jumon-gassen.html` の1ファイルにまとまっています。

- **画面**：タイトル（相手選択）、戦闘、結果の3画面です。
- **3D描画**：three.js で境内の舞台、術師、光線、火花、結界を描いています。キャラクターは図形を組み合わせたオリジナルのモデルで、画像ファイルは使っていません。
- **効果音**：Web Audio API で、その場で音を合成しています。

## 調整

難易度はスクリプト冒頭の `FOES` と定数で変えられます。

| 項目 | 意味 |
|---|---|
| `base` | 敵の通常の押し込み速度（1秒あたり） |
| `mult` | 大技中の押し込み倍率 |
| `gap` | 大技と大技の間隔（秒、最小と最大） |
| `warn` | 構えから大技までの予兆時間（秒） |
| `dur` | 大技の持続時間（秒） |
| `TAP_PUSH` | 連打1回で押し返す量 |
| `BARRAGE_TAP` | 大技中の連打の効率 |
| `GUARD_FACTOR` | ガード中に受ける押し込みの倍率 |
| `HOLD_MS` | 長押しと判定するまでの時間（ミリ秒） |
| `COUNTER_SEC` / `COUNTER_MULT` | 反撃の時間と、連打の倍率 |

衝突点の位置は0〜100の値で管理しています。50から始まり、100で勝ち、0で負けです。
